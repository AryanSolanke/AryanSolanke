### 🌟 Featured Projects

#### 🩺 [Sepsis Prediction System](https://github.com/AryanSolanke/sepsis-prediction-project)
Predicts sepsis early from ICU time-series data using machine learning, enabling timely clinical intervention.
- **Contribution:** Built end-to-end — from data pipeline to deployed API
- **Tech:** Flask (REST API), pandas, NumPy, scikit-learn, XGBoost, SHAP, joblib, matplotlib, seaborn · React (TypeScript) frontend · deployed on Render
- **Result:** 81.08% accuracy despite a 1.8% class imbalance
- 🔗 [Live Demo](https://sepsis-prediction-project.onrender.com)

#### 📦 [Delivery Delay Prediction System (GNN)](https://github.com/AryanSolanke/Delivery_Delay_Prediction_System_GML)
Predicts package delivery dates using **Graph Neural Networks**, modeling logistics networks as spatial-temporal graphs to capture route dependencies, transit hub congestion, and supply-chain delays.
- **Status:** 🚧 Actively in development

#### 🤖 [Binance Trading Bot (CLI)](https://github.com/AryanSolanke/binance-trading-bot)
A Python CLI application that places orders on the Binance Futures Testnet (USDT-M), built with a clean, reusable structure, proper logging, and error handling.
